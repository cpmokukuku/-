大连海事大学（DMU）教务系统自动抢课脚本

一个基于Tampermonkey（油猴）的超轻量自动抢课与名额监控脚本，专为大连海事大学教务系统（`jw.xpaas.dlmu.edu.cn`）设计。
还在为预选时什么课都没抢到、正选与开学第一周补选抢不过别人而苦恼吗？本脚本可以帮助您解决这一困惑。输入您想要“抢选”的课程名，便可以高枕无忧、等待某位同学退课或某两位计划进行课程交换的冤种同学们退课即可。
感谢Google Gemini对本脚本编写工作的帮助。

核心功能

悬浮控制面板 (UI)：页面右上角内置可视化控制面板，支持直接输入/修改目标课程名称，或启动/停止抢课功能。
名额实时监控：自动解析表格中课程的实时人数（e.g. 30/35），检测到空余名额立刻触发选课。
自主弹窗拦截：全自动拦截并确认系统的 `confirm`（是否提交）与 `alert`（提示信息）弹窗，彻底避免页面卡顿阻塞。
精准按钮识别：智能匹配“选课”操作链接，防止误触“课程简介”等无关链接。
双重停止机制：一旦成功触发选课或检测到课程处于“已选”状态，脚本会自动停止刷新，安全防护。
配置持久化：输入的课程名称与运行状态会自动保存在本地，刷新页面或重新打开浏览器无需重新设置。

安装与使用

1. 前置准备
请先确保浏览器已安装 [Tampermonkey (油猴)](https://www.tampermonkey.net/) 扩展。
2. 安装脚本
3. 开始抢课
1）在选课开放期间登录大连海事大学教务系统，进入“我的选课”=“选课”，看到必修、限选或任选分类界面后点击“进入选课”即可。
2）页面右上角会出现控制面板。
3）在输入框中填入目标课程的名称，点击 **“开始自动抢课”** 按钮即可。
